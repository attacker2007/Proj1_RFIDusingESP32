# Proj1_RFIDusingESP32

## Introduction
This is a mini-project that utilizies the RFID-RC522 module to build an access card attendance system. The project is build on a DOIT ESP32 DEVKIT V1, but is also possible on an Arduino Uno as it does not require much compute nor any wireless functionality in the ESP32. 

The list of equipment is as follows:
- DOIT ESP32 DEVKIT V1 + Expansion Board (optional)
- Breadboard (Mini)
- Male-Female Jumpers
- Buzzer
- Micro-USB to USB-A Wire Connector
